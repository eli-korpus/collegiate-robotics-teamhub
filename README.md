# TeamHub FTC

An open-source, bring-your-own-keys team dashboard for *FIRST* Tech Challenge teams.

- **Setup wizard** (`npm run setup`) — pick your teams, branding, and tabs from a library of 28; it builds your Supabase database for exactly those tabs.
- **Dashboard** — a lightweight, Spark-inspired web app with only the tabs you chose, hosted free on Cloudflare, Vercel, Netlify, or GitHub Pages.

> 🚧 Early development. The full build specification lives in [`TEAMHUB_FTC_SPEC.md`](./TEAMHUB_FTC_SPEC.md).
