# Announcements

**Purpose:** one-way messages to the team.

- Pinned posts stay on top. A post can include one compressed image.
- **Must read** posts notify everyone and show an "I've read this" button; captains and mentors see who hasn't read it.
- Unread dots are tracked on each device — no extra database rows.
- **No replies or comments.** Every post shows a link to your Team chat for questions.

**Not for:** discussion (Team chat), questions that need answers (Polls or People > Request info), a links library (Bulletin Board).

**Permissions:** post (Captains, Mentors), see read receipts (Captains, Mentors), edit/delete anyone's posts (Mentors).
