# Battery Tracker

**Purpose:** keep batteries charged and healthy.

- A card per battery: status (Charged / Needs charging / Weak — consider retiring), last charge, voltage and a voltage sparkline, charge-cycle count.
- One-tap logging: **Charged**, **Used**, **Test** (enter voltage), **Note**.
- Status is derived from the log and team-editable thresholds (charged ≥ 13.0 V, weak < 12.5 V, recharge after 48 h by default).
- Home shows "3 batteries need charging". Each battery keeps its latest 200 log entries.

**Not for:** general parts inventory (Parts Inventory hides its battery category when this tab is on).

**Permissions:** log (everyone), add/retire/delete batteries (Captains, Mentors).
