# Bulletin Board

**Purpose:** browse the team's links and resources.

- A sectioned, searchable view of the program's **one links list**: the same list that powers tool links in every tab.
- Pinned tool links (team chat, portfolio, Onshape…) appear at the top as "Team tools".
- Links only: no notes, comments or uploads. Turning this tab off never deletes links.

**Not for:** announcements (Announcements), files (your Drive tool link), discussion (Team chat).

**Permissions:** add links (Captains, Mentors; add Members in the wizard if you like), manage anyone's links (Mentors).
