# Parts Inventory

**Purpose:** what parts we have and where they are.

- Parts with SKU, vendor link, bin, quantity and an optional low-stock level; search, category filter, "low stock only".
- Big +/− buttons for taking and returning parts (anyone can change quantities; adding/editing parts is for managers).
- CSV import and export. "Request more" opens a pre-filled Purchase Request when that tab is enabled.
- One shared inventory for the program, or one per team (setup option). No images (link to the vendor page instead).
- With Battery Tracker enabled, battery categories are hidden here — batteries live there.

**Not for:** buying (Purchase Requests), batteries (Battery Tracker).

**Permissions:** change quantities (everyone), manage parts (Captains, Mentors, Inventory Manager).
