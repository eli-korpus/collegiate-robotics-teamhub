# Judging Prep

**Purpose:** practice judge interviews and track evidence for each award criterion.

- **Interview practice:** a question bank with talking points and who usually answers; drill mode picks random questions with a 90-second timer.
- **Award evidence:** your own list of awards and criteria (copy them from this season's manual, or start from a generic
  set — no award names are built in). Link each criterion to evidence (portfolio pages, notebook entries, photos);
  criteria without evidence are flagged.
- With Checklists enabled, a shortcut opens your judging/pit and portfolio checklists.

**Not for:** checklists (Checklists), writing engineering content (Engineering Notebook).

**Permissions:** view (everyone), manage questions and criteria (Captains, Mentors).
