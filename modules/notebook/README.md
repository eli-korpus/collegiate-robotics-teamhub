# Engineering Notebook

**Purpose:** the single place to document engineering work, design versions and decisions — and the source for your portfolio.

- **Log entries:** what we did and learned, with photos, tags, subsystem and authors.
- **Design iterations:** version (v1, v2…), what changed, *why*, Onshape link and an optional weighted **decision matrix**.
- **Subsystems view:** each subsystem's history v1 → vN side by side.
- Other tabs can pre-fill an entry with **Add to notebook** (repairs, driver practice, manufactured parts, outreach…).
- Export the filtered timeline as Markdown or print it to PDF for the portfolio. Comments on entries for review.
- Photos are compressed to WebP (≤ 400 KB, location data removed); up to 6 per entry.

**Not for:** to-dos (Tasks), announcements, storing CAD or big files (Onshape / Drive tool links).

**Permissions:** write (everyone), edit any (Captains, Mentors), manage subsystems (Captains, Mentors), delete any (Mentors).
