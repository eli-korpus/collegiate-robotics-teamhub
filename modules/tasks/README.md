# Tasks

**Purpose:** assign and track team work.

- **My tasks** groups your work into Overdue / Today / This week / Later — like a smart inbox.
- **Board** with drag-and-drop columns (rename them in setup) and an **All tasks** list with filters by person and subteam.
- Up to 5 assignees, due date, priority, subteam and an optional owning position. Comments on each task (not a chat).
- Assignees get a notification; done tasks older than 60 days are hidden unless you ask for them.
- The "New task" button also offers *Request a purchase*, *Submit a part to manufacture* and *Report a breakage* when
  those tabs are enabled — each opens the right tab.

**Not for:** buying things (Purchase Requests), making parts (To Manufacture), breakages (Repair Log), repeatable step lists (Checklists).

**Permissions:** create tasks (Members by default — setup option), assign to others (Captains, Mentors), edit any (Captains,
Mentors), delete any (Mentors). Assignees can always update their own tasks.
