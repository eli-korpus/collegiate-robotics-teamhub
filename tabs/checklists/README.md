# Checklists

**Purpose:** run through a list of steps, again and again: pre-match, pit setup, packing, inspection prep, judging/pit
display and portfolio.

- Phone-first: big checkboxes, sections, optional links on items (e.g. to the portfolio doc or a notebook entry).
- Start a **run** ("Qual 12"); two people can tick the same run together (live updates). Finish/reset for the next match.
- Generic starter templates you can edit. Nothing is tied to one season's game.
- Old runs are pruned after 30 days (the latest 20 per list are kept).

**Not for:** assigning work (Tasks), interview practice (Judging Prep).

**Permissions:** run checklists (everyone), create/edit checklists (Captains, Mentors).
