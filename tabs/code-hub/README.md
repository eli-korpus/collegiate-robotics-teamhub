# Code Hub

**Purpose:** the software team's page for repository activity, OpModes and driver controls.

- Recent commits and open pull requests from your public GitHub repository (the "Code repository" tool link; cached
  5 minutes; private repos just show the link).
- A list of your OpModes (autonomous, TeleOp, test) with status.
- **Gamepad mapping** per OpMode for both gamepads, drawn on a controller diagram. Drivers use it to learn the controls, and it fits in the portfolio.
- Library and docs links (SDK, Road Runner/Pedro, FTC Docs, gm0) as tool links.

**Not for:** storing code (GitHub), documenting decisions (Engineering Notebook).

**Permissions:** view (everyone), edit OpModes/controls (Captains, Mentors, Lead Programmer).
