# Rules Reference

**Purpose:** track rule questions and clarifications, and the rules worth remembering.

- **Questions:** anyone asks; captains/mentors record the official answer with a link to the Q&A forum or manual. The asker is notified.
- **Reminders:** short notes about easy-to-forget rules, with the rule number.
- Everything is tagged by season and searchable (including rule numbers like "G12").

**Not for:** hosting the manual (it's a tool link), general Q&A or chat (Team chat).

**Permissions:** post (everyone), answer and manage (Captains, Mentors).
